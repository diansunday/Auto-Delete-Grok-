# Auto-Delete-Grok-


Grok Imagine Auto-Delete Script

This script automates the deletion of favorite items on grok.com/imagine/favorites.

How it works:

It locates the first available listitem (image card).

It triggers a PointerEvent to bypass the UI framework restrictions.

It loops through all "More Options" buttons within that item to delete them.

It repeats until the page is empty.

Usage: Paste the code into your browser's Developer Console (F12) while on the Grok favorites page.
